# Complete Banking Data Analyst Portfolio

**START WITH `01_START_HERE_WINDOWS.md`.**

This folder includes three synthetic CSV datasets, an Excel KPI workbook, SQL analysis and PostgreSQL setup scripts, DAX measures, an interactive HTML prototype, a data dictionary, validation results, an executive PDF report, a PowerPoint, and interview/resume guidance.

**Important:** A native Power BI `.pbix` is NOT included because Power BI Desktop must be used on Windows to build/save it. The HTML dashboard is a prototype only. Do not represent synthetic case study work as actual employment or as a bank's real results.
